OFREY - SITIO WEB PUBLICITARIO

Archivos:
- index.html
- assets/ (fotografías)
- ofrey_website.zip (paquete completo)

Vista previa local:
1. Descomprime la carpeta.
2. Abre index.html con Chrome, Edge, Safari o Firefox.
3. La web funciona sin instalar programas.
4. Para ver los Reels incrustados necesitas conexión a Internet.

Publicación:
La carpeta completa es un sitio estático. Puedes publicarla en un hosting que acepte HTML/CSS/JS.
La opción más sencilla es un despliegue manual en Netlify:
1. Crea/inicia sesión en Netlify.
2. Usa Netlify Drop / Add new project.
3. Arrastra la carpeta ofrey_website completa.
4. Netlify te asignará una URL pública.
5. Después puedes conectar un dominio personalizado desde Domain management.
